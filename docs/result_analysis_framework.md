## 7. 结果分析

这一部分是老师最看重的内容，建议围绕“为什么会这样”来写。

可写内容：

- 对比从头训练与预训练：预训练模型明显更容易获得较高性能，说明 ImageNet 特征对该任务有迁移价值
- 对比线性探测与微调：线性探测在验证集上可能更快达到较高数值，但最后一层微调的测试集表现更好，说明适度解冻网络有助于适配目标域
- 对错误样例进行分析：主体较小、遮挡明显、背景复杂、光照变化大时更容易误判
- 结合混淆矩阵说明哪一类更容易被混淆，以及原因可能是什么
- 结合训练曲线讨论学习率：
	- 学习率过大可能导致收敛不稳定
	- 学习率过小可能导致训练速度慢
	- 本次实验中 1e-4 更适合微调场景
